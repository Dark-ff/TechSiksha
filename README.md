# Computer Literacy Field Project Website

Static, offline-friendly MVP for a Class 6 and 7 Computer Literacy Field Project.

## Open

Open `index.html` in a browser, or serve this folder with any static file server.

## What is included

- Home, Learn, Practice, Progress, Final Project, and About sections
- Eight data-driven lessons:
  - Computer Fundamentals
  - Windows and File Management
  - Microsoft Word
  - Microsoft Excel
  - Microsoft PowerPoint
  - Internet, Email, and Google Drive
  - Canva and AI Tools
  - Introduction to Coding and Scratch
- Village analogy cards, step flows, concepts, practical activities, recaps, and quizzes
- Auto-scored quizzes with best score saved in localStorage
- Activity status tracking
- Student self-assessment checklist
- Final project checklist and 20-mark rubric
- Reset Progress control
- Search across lessons and glossary
- Mobile-first responsive layout
- Service worker for basic offline caching after first load
